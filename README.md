# 🔐 Cyber Password Security Toolkit

A Python-based cybersecurity project that analyzes password strength, generates secure passwords, and provides smart security suggestions. It demonstrates core cybersecurity concepts like hashing, password safety, and pattern detection.

---

## 🚀 Features

- 📊 Password Strength Analyzer (0–100 scoring system)
- 📈 Progress Bar visualization
- 🧠 Smart Security Suggestions Engine
- 🔐 Strong Password Generator
- 🧾 Secure Password Storage using SHA-256 Hashing
- ⚡ Simple and fast command-line interface (CLI)

---

## 🧠 What This Project Does

This tool helps users:

- Check how strong their password is
- Generate strong random passwords
- Learn how secure passwords are created
- Store passwords safely using hashing

---

## 🛠️ Technologies Used

- Python 3
- Regex (re module)
- hashlib (SHA-256 encryption)
- random module
- string module
- time module
